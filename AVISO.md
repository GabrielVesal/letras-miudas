# Aviso

- O **letras-miudas** é um projeto independente, sem vínculo com as empresas acompanhadas.
- Os textos pertencem às respectivas empresas. Eles são públicos e ficam arquivados aqui com finalidade de transparência, pesquisa e informação, com indicação da fonte em cada arquivo.
- A conversão para Markdown é automática e pode conter erros. A versão que vale é sempre a publicada pela empresa.
- Em alguns documentos sai do texto o que não vale para o Brasil (avisos só para residentes nos EUA, versões inteiras para a Europa). Esses cortes ficam declarados em `empresas/<empresa>.json`.
- As versões antigas vêm do [Wayback Machine](https://web.archive.org/). A data de cada versão é a da captura do arquivo, que pode ser posterior à publicação real. Cada commit histórico tem o link da captura para conferência.
- Versões que só mudavam a formatação, ou que eram capturas parciais, teste A/B ou a versão de outro país (um trecho some e volta logo depois), foram descartadas do histórico. O método está descrito no [README](README.md#o-histórico-do-git).
- Nada aqui é orientação jurídica. Em caso de problema com uma empresa, procure o Procon, o consumidor.gov.br ou um advogado.

Alguma empresa quer pedir correção ou remoção? Abra uma issue.
